MOHIT PATHAK — PORTFOLIO WEBSITE

Files:
- index.html: page content
- style.css: light, responsive visual design
- script.js: mobile menu and current year
- professional-photo.png: your supplied professional portrait

HOW TO RUN:
1. Keep all four files in the same folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or install the Live Server extension and use "Open with Live Server".
4. In index.html, replace https://www.linkedin.com/ with your personal LinkedIn profile URL.

Before publishing:
- Verify the bio and academic details.
- Add your actual LinkedIn URL.
- Add a phone number only if you want it public.


CUSTOMIZE CERTIFICATE:
